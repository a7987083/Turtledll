AURA4-D1's duration discovery module was independently implemented against
observed client behavior and public classic server protocol/source evidence.

AURA4-D2 intentionally matches Nampower's public self-duration event ids and
payload shape (BUFF_UPDATE_DURATION_SELF=580 / DEBUFF_UPDATE_DURATION_SELF=581)
for dual-backend Lua compatibility. Preserve the Nampower BSD notice when
redistributing this derived compatibility layer.
