# AURA6-D4-R3 实机测试

这轮只测试最终效果，不看底层诊断计数。

## 只做 3 件事
1. 对一个怪物使用 **1 星割裂**，看 UI 中割裂的“总时长”。
2. 再测试 **5 星割裂**，总时长应该明显更长，并显示 **组合点预测**。
3. 等割裂自然消失，UI 中该 Aura 行也应该消失。

可选：再测试肾击，确认它同样走组合点预测。

## 通过条件
- 自己施加的目标 Aura 能显示剩余时间。
- 组合点技能显示 `组合点预测`。
- 1 星与 5 星割裂的总时长不同，5 星更长。
- 刷新后倒计时重新开始。
- Aura 实际仍存在时，即使预测值异常耗尽，也不会被 DLL 从 Aura 状态中删除。
