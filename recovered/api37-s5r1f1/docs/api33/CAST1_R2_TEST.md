# CAST1-R2 实机验收

窗口自动打开，不需要命令。

只做三步：

1. 让当前目标开始一次有读条的施法。
2. 下一次读条时用脚踢打断。
3. 自己成功释放一次技能，瞬发也可以。

通过时顶部显示：

`● CAST1-R2 完整通过`

三项含义：

1. 读条事件到达时，`Cast.State.Get/GetByGuid` 能立即读到 `phase=CASTING`、`active=true`。
2. 脚踢随后产生 STOP 后，记录已经 `phase=IDLE`，但 `result` 仍然保留 `INTERRUPTED`。
3. 自身技能结束后，记录仍然保留 `result=SUCCESS`，不会被 STOP 覆盖。

底层必须同时满足：

- 统一状态核心：正常
- 客户端时钟：正常（`CLIENT_ENGINE_MS`）
- 动态事件注册：10/10
- 解析失败：0
- 游标越界：0
- 打断入口：正常

引导施法为可选项，不影响本轮通过。
